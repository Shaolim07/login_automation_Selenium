## Sobre

Projeto prático de Selenium para treinamento de automação de testes com Java e JUnit 5

## Tecnologias
- Selenium Webdriver 4.20.0
- JDK 22
- JUnit 5

## Como executar

1. Clonar o repositório, e executar o comando:
```
mvn test
```
